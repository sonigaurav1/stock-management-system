1. **Graph-First**

   - Check docs before implementing

   - Data isolation patterns explicit

   - Security built-in

4. **Pattern-Based**

   - Don't invent new patterns
   - Consistency enforced

5. **Token-Efficient**
   - Structured docs instead of raw code
   - Compressed graph instead of massive files

   - Documentation keeps code current
