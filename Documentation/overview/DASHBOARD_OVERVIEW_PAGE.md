# Dashboard Overview Page - Brief Overview

**Access:** `http://localhost:3000/dashboard/overview` (authenticated users only)
/dashboard/overview = operations

## Purpose

Main business intelligence dashboard for inventory and company analytics.

## 10+ Dashboard Tabs

| Tab             | Focus                                            |
| --------------- | ------------------------------------------------ |
| **Widgets**     | Customizable data cards and KPIs                 |
| **Analytics**   | Revenue trends, order analysis, sales metrics    |
| **Finance**     | Profit & loss, cash flow, budget tracking        |
| **Inventory**   | Stock levels, movements, optimization insights   |
| **Sales**       | Order status, customer trends, revenue breakdown |
| **Customers**   | Customer segments, lifetime value, activity      |
| **Forecasting** | Predictive analytics, demand projections         |
| **Reports**     | Generated reports, exports, historical data      |
| **Settings**    | Dashboard configuration, widget preferences      |
| **Cash Flow**   | Payment status, cash position, forecasts         |

## Features

- Real-time data visualization
- Interactive charts and graphs
- Export functionality
- Dashboard customization
- Filter and segment options
- Mobile-responsive design

## Navigation

Horizontal tabs organize different analytical views. Use icons and labels to navigate. Each tab loads independently with its own data and filters.

## Enterprise Features

- Role-based widget visibility
- Scheduled report generation
- Custom metric configurations
- Data export capabilities
