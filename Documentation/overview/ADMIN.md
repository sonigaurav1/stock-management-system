# Admin Dashboard - Brief Overview

**Access:** `http://localhost:3000/admin`
/admin = company management

## Setup

Set `NEXT_PUBLIC_ADMIN_USER_ID` in `.env.local` with your Clerk user ID.

## 8 Main Sections

| Section       | Purpose                                                                       |
| ------------- | ----------------------------------------------------------------------------- |
| **Dashboard** | KPI overview, real-time metrics, system status, pending tasks                 |
| **Analytics** | Business intelligence: revenue trends, orders vs customers, sales by category |
| **Company**   | Organization info, documents, locations, compliance status                    |
| **Team**      | User management, invitations, roles, permissions                              |
| **Audit**     | Activity logging, filter by action/status, export reports                     |
| **Feedback**  | Customer feedback, admin responses, image attachments                         |
| **Reports**   | Generate sales, inventory, and user analytics reports                         |
| **Settings**  | Security, email config, integrations                                          |

## Key Features

- Real-time data updates
- Role-based access control
- Audit trail for compliance
- Multi-location support
- Export capabilities

## Navigation

Use the tab-based interface to switch between sections. Each tab loads independently with relevant filters and actions.
