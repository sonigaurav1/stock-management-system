# System Workflow Definition

Systematic approach for all development on Invento.

## For AI Assistants

Every feature implementation follows this:

1. Load PROJECT_GRAPH.md (~500 tokens)
2. Read relevant module docs
3. Check CODE_PATTERNS.md for examples
4. Implement following CONVENTIONS.md
5. Self-review with graph tools

**Result**: Features in 30 min vs 2+ hours

## For Developers

1. Read QUICK_START.md
2. Read ARCHITECTURE.md
3. Follow modules/{MODULE}.md for your work
4. Reference CODE_PATTERNS.md & CONVENTIONS.md
5. Check TROUBLESHOOTING.md if stuck

## Documentation First

Always check docs before:
- Implementing code
- Creating utilities
- Making architectural decisions

Docs are source of truth.
