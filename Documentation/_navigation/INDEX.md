## 📊 Documentation Standards

### For Developers
- **Clarity**: Assume intermediate knowledge (1-2 years experience)
- **Examples**: Every guide includes copy-paste code examples
- **Cross-references**: Link to related documentation
- **Status**: Current, tested, production-ready

### For AI Agents
- **Structure**: Organized by use case and module
- **Completeness**: Full context for autonomous work
- **Patterns**: Reusable, tested patterns
- **Types**: Complete TypeScript type information

### Maintenance
- **Location**: `/Documentation/` folder
- **Version**: Semantic versioning in headers
- **Review**: Update during code changes
- **Archive**: Move superseded docs to `/Archive/`
